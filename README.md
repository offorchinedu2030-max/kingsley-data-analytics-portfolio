Overview
The Sales Target Performance Dashboard is a Power BI project designed to provide interactive insights into sales performance against predefined business targets. It enables stakeholders to monitor KPIs, identify trends, evaluate product performance, and make data-driven business decisions.

Objectives
- Compare actual sales with sales targets.
- Measure overall sales performance.
- Identify top-performing and underperforming products.
- Monitor KPIs.
- Provide actionable insights.

Dashboard Features
- Executive KPI Cards
- Sales vs Target Comparison
- Product Performance Analysis
- Category Distribution
- Funnel Analysis
- Interactive Filters (Slicers)

Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Excel/CSV

- Business Value
- Monitor performance in real time.
- Identify gaps between targets and actual sales.
- Support strategic decision-making.
